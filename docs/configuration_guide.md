# Описание методов конфигурации агентов и инструментов

## Конфигурация через конфигурационные yaml файлы

Для того чтобы сконфигурировать агента и его инструменты с помощью yaml файлов,
необходимо подготовить файлы конфигурации, которые будут соответствовать следующей структуре.
См. примеры конфигурационных файлов в модуле `agent` в [каталоге ресурсов](../agent/src/main/resources/config)

### Структура конфигурационного yaml файла агента

```yaml
# Конфигурация агента разработчика
agent:
  # Имя агента
  name: "Sample name"

  # Описание функций агента
  description: "Agent will do anything for. Maybe effective, maybe not"

  # Модель, которая должна использоваться агентом
  model: "model:1337b"

  # Путь до системного промпта в папке ресурсов проекта
  system_prompt: "config/agents/sample/system_prompt.md"

  # Набор инструментов в виде их alias'ов, который доступен агенту. 
  # Должны быть описаны в отдельных конфигурационных файлах и находиться в изолированном каталоге
  toolset: [
    "search", "edit", "dance",
  ]
```

### Структура конфигурационного файла инструмента

На каждый отдельный инструмент должен быть отдельный файл конфигурации

```yaml
# Конфигурация агента разработчика
tool:
  # Псевдоним инструмента под которым он будет зарегистрирован в реестре инструментов
  alias: "create_directory"

  # Имя инструмента
  name: "Create directory"

  #
  description: "Создать новый каталог"

  # Список параметров инструмента (json schema).
  # Порядок и имена параметров должны совпадать с теми, что указаны в сигнатуре метода,
  # который вызывает инструмент.
  parameters:
    - parameter:
        # Имя параметра
        name: "dirPath"

        # Тип параметра (см. типы данных в json)
        type: "string"

        # Описание параметра для агента
        description: "Абсолютный путь к файлу в формате системы"

  # Референс на метод, который должен выполнить инструмент
  method: "ru.vych.tools.FileTools#createDirectoryIfNotExists"
```

Далее следует использовать конфигурируемый агент `ConfigurableAgent`

```java
// Создание клиента
var client = new OllamaClient();

// Регистрация инструментов в реестре
ToolRegistry.scanResourcesForConfigs("config/tools");

// Создание агента на основе конфигурационного файла
var agent = new ConfigurableAgent(
        client,
        AgentConfig.loadFromFile(
                "config/agents/dev/config.yaml", PathType.RELATIVE_TO_RESOURCES
        )
);
```

Теперь агент готов к полноценному использованию -
`agent.chat("Привет!")`
